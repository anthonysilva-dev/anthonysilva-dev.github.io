# Laboratório — Validação de Formulários

## Autor
Anthony da Silva Cavalcante

## Descrição
Formulário de inscrição para escola técnica com validação HTML e JavaScript.

## Funcionalidades
- Validação em tempo real de nome, e-mail, senha e mensagem
- Máscara de telefone automática
- Indicador de força da senha
- Contador de caracteres da mensagem
- Preview da imagem enviada
- Destaque visual de campos válidos e inválidos

## Arquivos
- index.html — estrutura do formulário
- css/style.css — estilos
- js/util.js — funções auxiliares
- js/validacoes.js — regras de validação
- js/app.js — lógica principal
